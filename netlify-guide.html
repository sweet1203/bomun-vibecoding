내 앱을 링크로 공유하기

Gemini Canvas로 만든 앱을 학생·동료가 휴대폰으로 여는 주소(○○.netlify.app)로 바꿔요.

Netlify Drop 무료 구글 계정으로 로그인
1

코드를 index.html로 저장하기

  • Canvas에서 코드 보기 → 코드 전체 복사
  • Windows메모장에 붙여넣기 → 다른 이름으로 저장
    파일 이름 index.html · 파일 형식 모든 파일 · 인코딩 UTF-8
  • Mac텍스트 편집기에 붙여넣기 → 메뉴 포맷 → 일반 텍스트로 만들기 → index.html로 저장

앱마다 폴더를 하나씩 만들고 그 안에 저장해요. 파일 이름이 모두 index.html이라 같은 곳에 두면 덮어써져요.
예) 바탕화면 › 자리배치 › index.html · 바탕화면 › 모둠뽑기 › index.html
저장한 파일을 더블클릭해서 잘 열리는지 먼저 확인해요.

2

Netlify Drop에 끌어다 놓기

인터넷 주소창에 app.netlify.com/drop 을 열고, index.html 파일을 Drop here 상자에 끌어다 놓아요.

그림·파일이 여러 개인 앱은 그 파일들이 든 폴더째 끌어다 놓아요.

3

구글로 로그인해서 내 것으로 만들기

몇 초 뒤 주소가 생기고, 프로젝트를 가져가라(Claim)는 안내가 나와요.

  • Google 계정으로 로그인하면 이 프로젝트가 내 것이 돼요.
  • 처음이면 가입 화면이 나와요. 무료 플랜 그대로 쓰면 돼요.

로그인하지 않으면 주소가 잠기거나 나중에 사라질 수 있어요.

4

주소 확인하고 공유보드에 올리기

  • ○○.netlify.app 주소를 복사해요.
  • 로그인하지 않은 시크릿 창에 붙여넣어 열리는지 확인해요.
    Chrome 시크릿 창: Ctrl+Shift+N (Mac ⌘+Shift+N)
  • 오른쪽 아래 QR의 패들렛에 주소와 한 줄 소개를 올려요.

고쳤을 때는?

Netlify에서 내 프로젝트를 열고, 배포(Production deploys) 영역에 고친 파일을 다시 끌어다 놓아요.

같은 주소로 바뀐 내용이 올라가요.

막혔을 때

비밀번호를 물어봐요 → 3단계 로그인을 했는지 확인

흰 화면 · 글자 깨짐 → 이름이 index.html인지, UTF-8로 저장했는지 확인

주소 이름 바꾸기 → 프로젝트 설정에서 이름 변경

꼭 지켜요

주소를 아는 사람은 누구나 열 수 있어요.

학생 이름·성적·출결 같은 개인정보가 든 파일은 올리지 않아요.
