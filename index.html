말로 만드는 나만의 학교 도구

코딩을 몰라도 괜찮아요. AI에게 말로 설명해서 수업·학급·업무에 쓸 도구를 하나씩 만들어 들고 가요. 오늘은 아무것도 설치하지 않아요.

시작 전 확인

체크하면서 준비해 주세요. 막히면 손을 들어 주세요.

오늘의 흐름

3시간 기준이에요. 중간에 10분 쉬어요.

  1. 15분
    바이브코딩 보기강사가 자리 배치 프로그램을 말로 만들고 고치는 모습을 봐요.
  2. 15분
    동료 교사 사례수학·국어·영어 선생님이 만든 수업 도구를 둘러봐요.
  3. 30분
    다 같이 첫 앱 완성레시피 카드 「랜덤 모둠 편성 & 발표자 뽑기」를 모두 함께 만들어요.
  4. 70분
    내 트랙 골라 만들기수업 · 학급 · 업무 중 하나를 골라 만들고 세 번 이상 고쳐요.
  5. 20분
    잘 쓰는 법개인정보, AI 결과 확인, 저장과 공유 방법
  6. 20분
    갤러리 워크공유보드에 내 작품을 올리고 서로 써 보며 댓글을 남겨요.

만드는 법 4단계

모든 레시피가 이 순서예요.

  1. Canvas를 켜고 프롬프트 붙여넣기레시피 카드의 「프롬프트 복사」를 눌러 붙여넣고, 노란 [대괄호]만 내 상황으로 바꿔서 보내요.
  2. 직접 눌러 보기오른쪽 미리보기에서 버튼을 눌러 보고, 이상한 곳이나 더 있었으면 하는 기능을 찾아요.
  3. 한 번에 하나씩 말로 고치기「↻ 고쳐 보기」 문장을 누르면 복사돼요. 여러 개를 한꺼번에 시키면 엉키기 쉬워요.
  4. 공유하거나 파일로 저장하기공유 버튼으로 링크를 만들거나, 코드를 .html 파일로 저장해요. 방법은 아래 「막혔을 때」에 있어요.
내 아이디어로 만들 때

무엇을 + 누가·어디서 쓰나 + 기능 3~5개 + 모양 + "하나의 HTML 파일로"

예) 수업 끝 5분 복습용 OX 퀴즈를 전자칠판에 띄워 쓸 거야. 10문제, 정답 효과음, 점수. 글씨 아주 크게. 하나의 HTML 파일로.

막혔을 때

자주 막히는 순서대로예요. 그래도 안 되면 손을 들어 주세요.

Canvas가 안 보여요

입력창 근처의 「도구」 메뉴 안에 있을 수 있어요. 학교(Workspace) 계정에서는 기능이 꺼져 있는 경우가 있어요.

→ 개인 구글 계정으로 다시 로그인하거나, ChatGPT의 캔버스를 써요.

미리보기 없이 코드만 길게 나와요

Canvas를 켜지 않고 보낸 경우예요. Canvas를 켠 뒤 이렇게 말해요.

방금 코드를 캔버스에서 미리보기로 보여 줘.
화면이 하얗거나 버튼이 안 눌려요
화면이 하얗게 나와. 오류를 찾아서 고쳐 줘.

어떤 버튼을 눌렀을 때 무엇이 안 되는지 구체적으로 말할수록 잘 고쳐요.

고칠수록 점점 이상해져요
처음 요구사항만 남기고 더 단순하게 다시 만들어 줘.

Canvas에서 이전 버전으로 되돌릴 수도 있어요. 다시 고칠 때는 한 번에 하나씩만 요청해요.

일부만 바뀌고 나머지가 사라졌어요
고친 부분까지 합쳐서 전체 코드를 다시 줘.
공유 링크를 만들고 싶어요

Canvas 화면의 공유 버튼으로 링크를 만들 수 있어요. 받는 사람이 로그인해야 열리는 경우가 있으니, 학생에게 주기 전에 다른 브라우저(시크릿 창)에서 열어 확인해요.

.html 파일로 저장하고 싶어요

1. Canvas의 코드 보기에서 코드 전체를 복사해요.

2. 메모장(Mac은 텍스트 편집기의 「일반 텍스트」)에 붙여넣어요.

3. 「다른 이름으로 저장」 → 파일 형식 모든 파일, 인코딩 UTF-8, 이름 끝을 .html로 저장해요. 예) 자리배치.html

4. 저장한 파일을 더블클릭하면 브라우저에서 열려요. 인터넷 없이도 대부분 작동해요.

엑셀 파일을 넣어도 반응이 없어요

엑셀을 읽는 도구를 인터넷에서 받아 오는 경우가 많아요. 인터넷 연결을 확인하고, 그래도 안 되면 이렇게 말해요.

엑셀 파일을 끌어다 놓아도 반응이 없어. 파일 고르기 버튼도 만들고, 읽기 오류가 나면 화면에 이유를 보여 줘.

세 가지 약속

AI로 만든 도구를 학교에서 쓸 때 꼭 지켜 주세요.

개인정보는 넣지 않기이름·성적·출결 파일을 AI 채팅창에 올리지 않아요. 번호나 가짜 데이터로 만들고, 실제 파일은 완성된 도구에 내 컴퓨터에서 넣어요.
결과는 직접 확인하기AI가 만든 문제·해설·공식·계산은 그럴듯해도 틀릴 수 있어요. 학생에게 주기 전에 한 번씩 검산해요.
판단은 교사가채점·출결·생활지도의 최종 결정은 선생님이 해요. 도구는 확인할 것을 골라 주는 역할까지예요.
