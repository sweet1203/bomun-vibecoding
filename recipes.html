바이브코딩 레시피 카드

설문에서 선생님들이 만들고 싶다고 하신 것들을 복사해서 바로 쓰는 프롬프트로 정리했어요. 노란색 [대괄호] 부분만 내 교과·내 반에 맞게 바꾸면 돼요.

이렇게 쓰세요

  1. Gemini(또는 ChatGPT)를 열고 입력창의 Canvas 도구를 켜요. ChatGPT는 「캔버스」를 골라요.
  2. 아래 카드의 프롬프트 복사를 눌러 붙여넣고, 노란 [대괄호]만 내 상황으로 바꿔서 보내요.
  3. 오른쪽 미리보기에서 직접 눌러 보고, ↻ 고쳐 보기 문장으로 한 번에 하나씩 고쳐요.
  4. 마음에 들면 공유로 링크를 만들거나, 코드를 내려받아 .html 파일로 저장해요.

내 아이디어로 쓸 때의 공식

무엇을+누가·어디서 쓰나+기능 3~5개+모양+하나의 HTML 파일로

예) 「수업 끝 5분 복습용 OX 퀴즈를, 전자칠판에 띄워 쓸 거야. 10문제·정답 효과음·점수. 글씨 아주 크게. 하나의 HTML 파일로.」

막혔을 때 한 줄

  • 화면이 안 나와요 → 화면이 하얗게 나와. 오류를 찾아서 고쳐 줘.
  • 점점 이상해져요 → 처음 요구사항만 남기고 더 단순하게 다시 만들어 줘.
  • 일부만 바뀌었어요 → 고친 부분까지 합쳐서 전체 코드를 다시 줘.
학생 이름·사진·연락처·성적·출결 같은 개인정보는 AI 채팅창에 넣지 않아요. 번호나 가짜 데이터로 만들고, 실제 자료는 완성된 파일을 내 컴퓨터에서 열어 넣어요.
